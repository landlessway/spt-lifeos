# 🟡 02-阅读palace

## 职责

**输入层：阅读** — 完整的书籍学习体系，基于交互式学习理念。

---

## 成员

- `authors/` — 按作者组织的知识体系
  - 每个作者有自己的 profile（背景、核心思想、代表作品）
  - 每本书包含：
    - `reading-notes.md` — 正式阅读笔记
    - `reading-process.md` — 阅读过程记录（碎片思考、灵感）
    - `iterative-articles/` — 基于对话的迭代文章
- `reading/` — 正在阅读的书籍（兼容旧结构）
- `done/` — 已读完的书籍
- `待扫描/` — 新加入的书籍，等待处理

---

## 使用流程

```
1. 用户说"我要读 [作者] 的 [书名]"
2. AI 检查 authors/ 是否已有该作者
3. 如果没有，创建作者 profile
4. 创建书籍文件夹和三个文件：
   - reading-notes.md（正式笔记）
   - reading-process.md（过程记录）
   - iterative-articles/（迭代文章）
5. 开始交互式学习：
   - AI 提问确保理解
   - 用户回答后生成迭代文章
   - 建立与已有知识的链接
6. 读完后移动到 done/
7. AI 评估：内容够多？→ 提议升级到 01-知识系统/
```

---

## 触发词

- "我要读 [作者] 的 [书名]"
- "扫描一下 00-阅读系统/"
- "[书名] 读得怎么样了？"
- "读完了 [书名]"

---

## 知识去重功能

当你读同一作者的第二本书时，AI 会：
1. 扫描已有作者 profile 和之前的阅读笔记
2. 识别重复内容
3. 精准建议："可以跳过第一部的'成长'章节，聚焦第二部的新内容"

---

## 交互式学习机制

AI 主动提问、角色扮演、确保理解：
- 理解检查：用自己的话解释概念
- 应用场景：举一个生活中的例子
- 对比思考：这与之前的观点有什么不同？
- 费曼技巧：能说清楚才算真懂

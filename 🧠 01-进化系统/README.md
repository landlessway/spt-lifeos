# 🧠 01-进化系统/

## 职责

**进化层** — 系统的自我进化、洞见发现、预测推理。

---

## 成员

| 文件夹 | 说明 |
|--------|------|
| `insights/` | 洞见：你没想到的发现 |
| `predictions/` | 预判：根据历史推断未来 |
| `questions/` | 好问题：值得探索的方向 |
| `evolution_log.md` | 进化日志：系统如何变得更懂你 |

---

## 使用场景

### insights/
```
AI 发现："你的不同领域之间有共通模式"
    ↓
存入 insights/
    ↓
将来可回溯、调用
```

### predictions/
```
AI 根据："你连续3周在读哲学"
    ↓
预测："你可能想探索哲学与创作的结合"
    ↓
存入 predictions/
```

### questions/
```
AI 发现："有个问题你还没深入思考"
    ↓
存入 questions/
    ↓
将来可探索
```

### evolution_log.md
```
2026-04-10: 系统重命名完成
2026-04-15: 发现你的标题偏好模式
2026-05-01: 第一次主动预判成功
...
```

## 系统如何进化

```
第1周：AI 记住你的偏好

第12周：AI 主动提醒"你上次说的X，现在有新关联了"

```

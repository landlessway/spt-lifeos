# 🔵 04-内容创作

## 职责

**输出层：创作** — 创作辅助系统，基于dbs skill但进化出你自己的风格。

每个 Agent 是一个独立子系统，通过 A+B+C 反馈循环不断进化：
- A: 你主动说"这个好"
- B: 你反复选同类（行为模式）
- C: 数据告诉你"这篇爆了"

---

## 成员

| Agent | 基于 dbs 的什么 | 进化成什么 |
|-------|----------------|-----------|
| `选题Agent/` | 爆款选题公式、对标分析 | 你对"好选题"的判断直觉 |
| `叙事Agent/` | 内容结构、节奏控制 | 你的表达风格（分平台） |
| `标题Agent/` | 75 个爆款标题公式 | 你的标题直觉 |
| `平台参数/` | — | 各平台的格式要求 |

---

## 核心机制

### 风格隔离
```
叙事Agent/PROFILE.md
├── 推特风格：短平快、金句型
├── 视频平台教程风格：循序渐进、干货型
├── 观点视频风格：深度、逻辑型
└── 公众号风格：长文、结构化
```

学习记录打标签，互不干扰。

### 调用逻辑
```
你: 帮我写个推文

AI: 
  1. 识别平台：推特
  2. 调用 dbs-xhs-title skill
  3. 调用 叙事Agent/#推特风格
  4. 叠加：dbs 公式 + 你的推特风格
  5. 输出 10 个候选
  6. 你选择
  7. AI 记录选择 + 理由
```

### 进化循环
```
第1次：调用 dbs skill → 你选择 → 记录
第10次：识别你的偏好模式
第30次：数据反馈 → 更新爆款特征
第50次：输出越来越像你，不再依赖 dbs
```

## 每个 Agent 的结构

```
Agent/
├── README.md        # 职责、使用流程
├── PROFILE.md       # 风格画像（动态更新，分平台）
├── history.md       # 历史记录（带标签）
└── process.md       # 修改过程（最终版+中间版本）
```

---

## dbs skill 的角色

dbs 是**起点**，不是终点：
- 提供底层方法论和公式
- 你的选择 + 数据反馈 → 进化成你自己的模型
- 最终：你的第二大脑接管，dbs 只是备选工具

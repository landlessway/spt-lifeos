# ♻️ 03-思考系统

## 职责

**加工层：思考** — 存放已加工、已沉淀的有价值内容。

---

## 成员

| 文件夹 | 说明 |
|--------|------|
| `drafts/` | 草稿：未完成的想法 |
| `essays/` | 成文：完整的文章 |
| `scripts/` | 脚本：观点类视频文案 |

---

## 内容流向

```
drafts/ → essays/ → scripts/ → 🔵 04-内容创作 → 00-你的账号
   ↓          ↓           ↓
  草稿       成文        脚本
   ↓          ↓           ↓
🟡 02-碎片Agent  ♻️ 03-Wiki  🔵 04-表达系统
   ↓          ↓           ↓
  素材来源   知识沉淀    表达训练
```

---

## 使用场景

- 你有了一个想法 → `drafts/`
- 想法成型 → `essays/` → 索引化到 ♻️ 03-Wiki
- 要做成视频 → `scripts/` → 结合 🟡 02-ibooks-highlights 的金句
- 表达训练后 → 优质内容沉淀回 `essays/`
- 发布后 → 记录到 00-你的账号（隔离项目）

## 跨Agent关系

| 输入来源 | 加工后输出到 |
| --- | --- |
| 🟡 02-碎片Agent | fragments → essays |
| 🟡 02-阅读palace | 读书笔记 → essays |
| 🔵 04-表达系统 | 表达训练成果 → essays/scripts |
| 🟡 02-ibooks-highlights | 金句引用 → scripts |

| 输出到 | 功能 |
| --- | --- |
| ♻️ 03-Wiki | 成文内容索引化 |
| 🔵 04-内容创作 | 脚本直接用于创作 |
| 🧠 01-进化系统 | 优质思考沉淀为洞见 |

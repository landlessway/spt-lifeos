# 🟡 02-碎片Agent

## 职责

**输入层：碎片** — 随时随地收集灵感碎片（飞书/对话），整理成有逻辑的内容。

---

## 成员

| 文件夹 | 说明 |
|--------|------|
| `fragments/` | 碎片想法：临时的念头、观点 |
| `quotes/` | 金句：有价值的引用，按领域分类 |
| `published/` | 已发布：记录出处和平台 |

---

## 使用流程

### 碎片想法
```
你有个想法 → fragments/
    ↓
积累多了 → 整理到 ♻️ 03-思考系统/essays/
    ↓
进一步加工 → 🔵 04-内容创作
```

### 金句
```
飞书记录 → 手动触发"扫描飞书碎片"
    ↓
AI 拉取 → 分析分类 → quotes/领域.md
    ↓
创作时调用 → 被所有Agent调用（全局资源）
```

### 已发布
```
内容发布 → published/
    ↓
记录：平台、日期、数据
    ↓
反哺 → 🔵 04-内容创作 的风格进化
    ↓
优质沉淀 → 🧠 01-进化系统
```

---

## 飞书同步

- 手动触发："扫描飞书碎片"
- AI 通过飞书CLI拉取内容
- 整理成有逻辑的内容（不改变原意）
- 分类存储：fragments/、quotes/、published/

## 跨Agent关系

| 输出到 | 功能 |
| --- | --- |
| ♻️ 03-思考系统 | 碎片想法整理后成为成文 |
| 🔵 04-内容创作 | 金句作为创作素材 |
| 🔵 04-表达系统 | 金句增强表达说服力 |
| 🧠 01-进化系统 | 优质碎片沉淀为洞见 |

---

## 动态更新

- `quotes/` 按领域创建文件
- `fragments/` 自由添加
- `published/` 持续累积

# 🔵 04-表达系统

## 职责

**输出层：表达** — 通过深度对话训练表达能力，目标是在一定程度上达到像樊登或大冰那样的口才。

---

## 成员

- `⏳ 对话中/` — 正在进行的训练对话
- `✅ 已完成/` — 完成的训练对话
- `📊 风格提取/` — 从对话中提取的表达风格

---

## 工作流程

1. **开启对话**：用户在 `⏳ 对话中/` 创建新文件，说明主题
2. **AI 进入角色**：读取文件，开始提问
3. **用户回答**：通过语音输入直接写入文件
4. **AI 继续对话**：
   - 基于回答提出更深入的问题
   - 主动调用相关资源（iBooks highlights、阅读笔记）
   - 记录表达特点
5. **风格提取**：AI 从对话中提取风格，写入 `📊 风格提取/`

---

## 调用资源

AI 会主动调用：
- `🟡 02-ibooks-highlights/` — 相关金句
- `🟡 02-阅读palace/authors/` — 阅读笔记
- `♻️ 03-Wiki/` — 相关知识
- `🥷 00-用户OS/MEMORY/mentors/` — 导师框架

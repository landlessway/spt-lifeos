# 🟡 02-金句库 — 金句收藏

> **作用**：只读索引层，存放从各处收集的金句，全局可调用。

---

## 🎯 核心功能

### 金句收藏

收藏你觉得有价值的金句，包括：

- 书籍金句
- 文章金句
- 视频金句
- 对话金句

### 只读索引

**这是一个只读索引层**：
- 金句存放在这里后，**非必要不改编**
- 原句好就直接用，需要融合时再调整
- 保持原始语料的纯净性

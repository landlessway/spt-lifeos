# 🟡 02-X

## 职责

**输入层：Web收藏** — 存放所有外部输入内容（Twitter/X + Web文章），等待处理和归档。

---

## 成员

| 文件夹 | 用途 | 处理方式 |
|--------|------|----------|
| `X/` | 从Twitter/X收藏的文章 | 吸收学习后移动到 ♻️ 03-Wiki |
| `Web/` | 从其他网页爬取的文章 | 吸收学习后移动到 ♻️ 03-Wiki |

---

## 处理流程

1. 新内容进入对应文件夹
2. AI阅读并提取关键信息
3. 展示方案给用户确认
4. 决定处理方式：
   - 有价值 → 归档到 ♻️ 03-Wiki
   - 无价值 → 删除
   - 待定 → 保留在Web收藏

## 跨Agent关系

| 输入来源 | 处理后输出到 |
| --- | --- |
| 用户手动收藏 | X/ 或 Web/ |
| 用户触发"处理一下" | AI扫描分类 |

| 输出到 | 功能 |
| --- | --- |
| ♻️ 03-Wiki | 有价值的文章索引化 |
| ♻️ 03-思考系统 | 文章观点提取为成文 |
| 🔵 04-内容创作 | 作为创作素材 |

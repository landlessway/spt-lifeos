# IDENTITY/

## 职责

**身份层** — 定义你是谁、你的目标、你的偏好。

每次对话启动时，AI 自动加载这些文件，确保始终在上下文中。

---

## 成员

| 文件 | 内容 | 更新频率 |
|------|------|----------|
| `TELOS.md` | 使命、目标、核心信念 | 罕见变更 |
| `CONTEXT.md` | 当前状态、进行中的项目 | 持续更新 |
| `PROFILE.md` | 偏好画像、风格、习惯 | 频繁进化 |
| `BLINDSPOTS.md` | 盲点清单（你不知道自己不知道的） | 逐渐补充 |

---

## 变更规则

| 文件 | 变更权限 |
|------|----------|
| `TELOS.md` | 核心信念变更需用户审批（写入 pending_approvals） |
| `CONTEXT.md` | AI 可根据对话自动更新 |
| `PROFILE.md` | 通过 candidates.md 池晋升（你确认后） |
| `BLINDSPOTS.md` | AI 发现后提议，你确认后添加 |

---

## 启动注入

每次对话开始时，AI 自动读取：
1. `TELOS.md` — 理解你的使命
2. `CONTEXT.md` — 理解你当前在做什么
3. `PROFILE.md` — 理解你的偏好

确保 AI 的回应始终符合你的身份和状态。

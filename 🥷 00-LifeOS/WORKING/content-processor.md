# content-processor.md — 内容处理追踪

> 追踪旧内容和新增内容的 Wiki 化处理状态。

## 处理状态

| 状态 | 含义 |
|------|------|
| ⬜ 待处理 | 已纳入范围，尚未拆解 |
| 🔄 处理中 | Agent 正在拆解 |
| ✅ 已抽取 | 已生成内容单元，关系已补 |
| ⏭️ 跳过 | 不适合拆解 |
| 🔍 需复核 | 已抽取但需人工确认 |

## 纳入范围

（添加你要处理的内容来源，Agent 会自动更新状态）

## 使用方式

告诉 Agent："处理一下 [目录名] 的已发布内容"
AI 会扫描 → 拆解为 Wiki 单元 → 补关系 → 更新本表。

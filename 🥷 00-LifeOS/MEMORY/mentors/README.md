# mentors/

## 职责

存放**思维导师调用记录** — 费曼、Naval、塔勒布、x-mentor 等。

---

## 成员

| 文件 | 说明 |
|------|------|
| `费曼.md` | 使用费曼框架的记录 |
| `naval.md` | 使用 Naval 框架的记录 |
| `塔勒布.md` | 使用塔勒布框架的记录 |
| `x-mentor.md` | 使用 x-mentor 框架的记录 |

---

## 单个导师记录的格式

```markdown
# Naval

## 使用记录

### 2026-04-08 | 问题：如何选择学习方向
**调用的框架**：Naval 的杠杆思维
**问题**：有多个领域想学，不知道选哪个
**Naval 的建议**：[内容]
**你的反馈**：有帮助

### 2026-04-10 | 问题：XXX
...

## 效果评估
- 哪些场景好用：[记录]
- 哪些场景不好用：[记录]
- 你的变体：[你对框架的改造]

## 内化金句
- [你已经吸收的 Naval 式表达]

## 与其他框架的关系
- 和费曼的区别：[对比]
- 和塔勒布的互补：[对比]
```

---

## 调用逻辑

```
你: 用 Naval 的方式思考这个

AI:
  1. 读取 mentors/naval.md
  2. 了解你之前如何使用这个框架
  3. 了解哪些场景好用、哪些不好用
  4. 叠加：原始框架 + 你的变体
  5. 输出
  6. 记录本次调用
```

---

## 进化

```
第1次：使用原始框架
第10次：知道你在哪些场景喜欢用
第30次：了解你的变体
第50次：输出"你的 Naval 模式"，不是原始版
```

---

## 动态更新

- 每次调用后更新使用记录
- 不断积累效果评估
- 逐渐形成你的变体
